# Международный фиксированный календарь — v1.7

Конвертер дат между **8 календарями** на **17 языках** с полной доступностью.

## Что нового в v1.7

### 🎯 Полная доступность
- **Tab-навигация** по ячейкам календаря
- **Стрелки ←→↑↓, Home/End, PgUp/PgDn** — перемещение по дням
- **Enter/Space** — выбор дня
- **ARIA-роли**: `grid`, `gridcell`, `tablist`, `menu`, `menuitem`
- **aria-selected**, **aria-pressed**, **aria-expanded**, **aria-current**
- **Screen reader**: каждая ячейка озвучивается полностью («8 октября · 22 сентября МФК · День учителя»)
- **Live regions** для результата и разницы дат
- **Skip-link** в начало страницы
- **Фокус-ловушка** в меню языков (Tab не выходит за пределы)
- **Закрытие меню по Escape** с возвратом фокуса
- **Видимый фокус** (`:focus-visible`)

### 🌐 Новое меню языков по регионам
- 10 регионов с заголовками
- Счётчик языков в каждом регионе
- Пустые регионы показываются как «0» (затемнены)
- Навигация стрелками + Home/End
- Фокус-ловушка Tab

## Возможности

- **8 календарей**: Григорианский, Юлианский, Китайский солнечный, Еврейский, Индуистский, Исламский, Персидский, Коптский
- **17 языков** с полным переводом
- **42 праздника** + Пасха (западная и православная)
- **Экспорт в ICS** для календарей
- **Разница между датами**
- **URL-роутинг** и шеринг
- Светлая / тёмная тема
- Оффлайн-режим

## Клавиатурная навигация

| Клавиша | Действие |
|---------|----------|
| Tab / Shift+Tab | Перемещение между элементами |
| ←→↑↓ | Перемещение по дням календаря |
| Home / End | Первый / последний день недели |
| PgUp / PgDn | Предыдущий / следующий месяц |
| Enter / Space | Выбрать день |
| Escape | Закрыть меню языков |
