# Международный фиксированный календарь — v1.8

Конвертер дат между **8 календарями** на **18 языках**. Встроенные **тесты**.

## Что нового в v1.8

### 🇵🇹🇧🇷 Разделение португальского
- **Português (PT)** — европейский → Западная Европа
- **Português (BR)** — бразильский → Америка (Южная Америка)
- Итого: **18 языков**

### 🧪 Встроенные тесты
30 эталонных проверок:
- JDN ↔ Григорианский (8 известных дат)
- Round-trip все 8 календарей
- Високосные дни МФК
- Границы года (1, 9999)
- Прямые эталоны (Hebrew, Islamic, Persian, Coptic)

**Запуск:**
- Кнопка «Запустить тесты» в футере
- URL: `?test=1` или `#test`
- Из консоли: `runTests()`

## Возможности

- 8 календарей, 18 языков, 42 праздника
- Полная доступность (Tab, стрелки, ARIA, screen reader)
- Экспорт ICS, разница дат, URL-роутинг, шеринг
- Светлая / тёмная тема
